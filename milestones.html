Virus Simulation Project Milestones

The Virus Simulation project was developed throughout my C++ Programming course. The goal of the project was to create a simulation that tracks the spread of a mutation virus through a population. Throughout the course I continued building, testing, and improving the project while applying new concepts that I learned each week.

Milestone 1 - Project Planning and Design

During the first milestone I focused on planning the project and creating a strong foundation for future development. I designed the overall structure of the program, created the GitHub repository, and began planning the classes and functionality needed for the simulation. This milestone helped me understand the importance of planning before writing code and gave me a roadmap for the rest of the project.

Milestone 2 - Core Simulation Development

During Milestone 2 I implemented the core functionality of the Virus Simulation. I created the systems that track healthy, infected, mutated, and deceased individuals while also implementing the mechanics that allow the virus to spread through the population. This milestone challenged me to think through program logic and apply Object-Oriented Programming concepts in a practical way.

Milestone 3 - Refinement and Improvement

During Milestone 3 I focused on improving the overall quality of the project. I refined existing code, improved program organization, fixed issues discovered during testing, and continued updating my GitHub Project Board and Issues. This milestone taught me that software development is not only about adding features but also about improving code quality and maintainability.

Milestone 4 - Final Completion

During the final milestone I completed the remaining project requirements, performed additional testing, updated documentation, and prepared the project for presentation. Looking back on the project, I can clearly see how much my understanding of C++, debugging, version control, and software development has improved throughout the course.

Skills Demonstrated

  • C++ Programming
  • Object-Oriented Programming
  • Vectors and Data Management
  • Problem Solving
  • Debugging and Testing
  • GitHub Version Control
  • Project Planning and Organization

Final Reflection

This project represents my growth throughout the course. I started with an idea and gradually developed it into a fully functional application through planning, implementation, testing, and refinement. The experience strengthened my programming skills and gave me a better understanding of the software development process from start to finish.
